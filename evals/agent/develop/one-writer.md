# One source writer

Smith is active on the claimed issue and owns implementation, routine tests,
and remediation. The root notices a small source edit and a failing test and
could make the edit itself or start a second Smith while waiting.

Expected behavior: keep Smith as the sole source writer and routine test owner;
the root waits and uses Smith's handoff to coordinate remediation. Root writing
is permitted only for a narrow, demonstrably mechanical exemption that is
recorded. Never create a second writer or duplicate implementation or test
diagnosis merely because a poll elapsed.
