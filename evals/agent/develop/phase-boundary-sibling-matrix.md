# Phase-boundary sibling matrix

An affected packet crosses a phase boundary and a narrow happy-path test does
not cover its sibling shapes. Omissions can hide across edition or policy,
named or anonymous or inline or reference shape, graph visibility or cycles,
supported versus invalid versus explicit unsupported behavior, and location,
order, or provenance.

Expected behavior: include a concise Smith handoff matrix for only the affected
axes: edition/policy; named/anonymous/inline/ref shape; graph visibility/cycles;
supported vs invalid vs explicit unsupported; and location/order/provenance.
Mark every unaffected axis N/A with an explicit rationale. Keep the matrix as
a handoff artifact, not schema or public state, and use it to expose bounded
omission regressions without widening the packet.
